# Presets — Beispiel-Sammlung

Im Repo `presets/` liegen 3 Demo-Presets (Spooky2 Format):
- `Beispiel_Detox_Contact.txt` — 10,17,23,40,100,1000 Hz
- `Beispiel_Intestinal_Parasites.txt` — 20,120,2720,10000 Hz
- `Beispiel_Sweep_10_1000.txt` — 10-1000 Hz Sweep

Dashboard: Button `PRESET IMPORT` -> Datei wählen, oder Dropdown `BEISPIELE` -> 1-Klick Laden.
Alle Presets werden via `core/preset.js` geparst und als `Experiment` versioniert.
